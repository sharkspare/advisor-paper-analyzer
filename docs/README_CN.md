# 📚 谷歌学术论文爬虫工具 - 使用说明

## 🎯 这是什么？

这是一个帮助你快速获取谷歌学术（Google Scholar）上某位导师所有论文信息的小工具。

只需要简单几步操作，就能自动下载导师的所有论文信息，包括：
- 📝 论文标题
- 👥 作者列表
- 📅 发表时间
- 📖 发表期刊/会议

最终会生成Excel可以打开的表格文件，方便你查看和使用。

---

## 💻 系统要求

- ✅ Windows 7/8/10/11 系统
- ✅ 能访问谷歌学术（Google Scholar）的网络环境
- ❌ **不需要**安装Python或任何编程软件

## 🚀 快速开始（3步搞定）

### 第一步：找到导师的用户ID

1. 打开浏览器，访问 [谷歌学术](https://scholar.google.com)
2. 搜索你想查询的导师名字
3. 点击导师名字，进入他/她的个人主页
4. 看浏览器地址栏，会看到类似这样的网址：
   ```
   https://scholar.google.com/citations?user=AAAAAAAAAAAA&hl=zh-CN
   ```
5. 复制 `user=` 后面的那串字符（例如：`AAAAAAAAAAAA`）

**示例图解：**
```
网址: https://scholar.google.com/citations?user=qfaMS6EAAAAJ&hl=zh-CN
                                                 ↑↑↑↑↑↑↑↑↑↑↑↑↑
                                            这就是用户ID，复制它！
```

### 第二步：运行程序

1. 找到 `谷歌学术论文爬虫.exe` 文件
2. **双击**打开（如果杀毒软件弹出警告，点击"允许运行"或"信任"）
3. 会出现一个蓝色标题的窗口

### 第三步：输入信息并开始

1. **在"导师用户ID"框中**：粘贴刚才复制的用户ID
2. **在"爬取数量"框中**：输入你想获取的论文数量（默认200条）
   - 如果导师论文不到这个数量，程序会自动停止
3. **点击绿色的"🚀 开始爬取"按钮**
4. 等待程序运行（日志窗口会显示进度）
5. 完成后会弹出提示框，显示保存的文件位置

---

## 📂 结果文件在哪里？

程序运行完成后，会在**exe文件所在的文件夹**生成两个文件：

1. **`papers_用户ID.csv`** 
   - 📊 表格格式
   - 可以用Excel、WPS等软件打开
   - 适合数据分析和整理

2. **`papers_用户ID.txt`**
   - 📄 纯文本格式
   - 可以用记事本打开
   - 适合直接阅读

**例如：** 如果用户ID是 `qfaMS6EAAAAJ`，生成的文件就是：
- `papers_qfaMS6EAAAAJ.csv`
- `papers_qfaMS6EAAAAJ.txt`

## ❓ 常见问题解答

### Q1: 双击exe后没反应？
**A:** 可能被杀毒软件拦截了
- 检查杀毒软件通知
- 将程序添加到"信任列表"或"白名单"
- 或者临时关闭杀毒软件再运行

### Q2: 提示"无法连接"或"请求失败"？
**A:** 网络问题
- 确保你能正常访问 scholar.google.com
- 如果在国内，可能需要使用科学上网工具
- 检查防火墙是否阻止了程序

### Q3: 获取的论文数量比预期少？
**A:** 这是正常的！
- 可能导师实际发表的论文就这么多
- 有些论文可能未公开或未收录
- 程序会自动停止在论文列表末尾

### Q4: CSV文件打开是乱码？
**A:** 编码问题
- 用Excel打开时，选择"UTF-8"编码
- 或者直接用WPS表格打开（通常会自动识别）
- 也可以查看TXT文件，不会乱码

### Q5: 想爬取多个导师的信息怎么办？
**A:** 很简单！
- 每次输入一个导师的用户ID
- 运行完成后，再输入下一个
- 生成的文件名包含用户ID，不会覆盖

### Q6: 可以中途停止吗？
**A:** 可以！
- 点击橙色的"⏹ 停止"按钮
- 已经获取的数据会保留
- 下次可以重新开始

### Q7: 能在Mac或Linux上用吗？
**A:** 抱歉不能
- 这个exe文件只能在Windows系统运行
- 如果需要Mac/Linux版本，需要用Python源码运行

### Q8: 程序安全吗？会不会泄露信息？
**A:** 完全安全！
- ✅ 不会上传任何数据
- ✅ 不会连接除谷歌学术外的服务器
- ✅ 所有数据都保存在本地
- ✅ 开源代码，可审查

## 🤖 进阶技巧：AI深度分析导师科研状况

获取到论文数据后，你可以利用AI（如ChatGPT、Claude、文心一言等）对导师进行**深度分析**，这是一个非常实用的高级技巧！

### 为什么要用AI分析？

- 📊 **自动统计**：AI能快速统计论文数量、发表趋势
- 🔍 **趋势分析**：识别研究方向的演变和拓展
- 👥 **合作网络**：分析核心合作者和署名习惯
- 💡 **智能推理**：判断导师当前科研状态（一线/行政岗）
- 📈 **影响力评估**：识别高被引论文和学术贡献

### 操作步骤

**第1步：准备数据**
1. 打开生成的 `papers_用户ID.txt` 文件
2. 按 `Ctrl+A` 全选内容
3. 按 `Ctrl+C` 复制

**第2步：使用AI分析**
1. 打开AI对话工具（ChatGPT/Claude/文心一言等）
2. 粘贴下面的分析Prompt
3. 然后粘贴你复制的论文数据
4. 等待AI生成分析报告

### 推荐分析Prompt（可直接复制使用）

```
基于文件中的论文、发表时间、作者署名、研究领域等全部信息，
完成以下分析，分析需有**数据支撑**（如引用具体发表年份、
论文篇数、作者排序等）： 

1. 主要研究方向：按论文发表的时间线梳理（可按近5年/10年/
   职业生涯分阶段），明确各阶段的核心研究领域、研究方向的
   演变/拓展趋势；

2. 科研现状推理：先统计该导师论文的**年度发表数量**（近10年），
   标注发表高峰/低谷期，再结合最新发表论文的时间、作者合作
   模式，判断其目前是否处于科研一线、是否转向行政岗/指导
   学生为主，给出明确的推理依据；

3. 论文作者署名习惯：统计学生为第一作者的论文占比（若有标注），
   明确该导师的署名位置（多为通讯作者/共同一作/第二作者等），
   分析不同研究方向的署名规律；

4. 补充信息：梳理该导师的高被引论文（被引数靠前的3-5篇）、
   核心合作作者/合作单位，总结其科研影响力。

若内容缺失或无相关信息，需明确告知缺失的具体维度，
并说明无法分析的原因。
```

AI会为你生成类似这样的分析报告：

```
【导师科研状况分析报告】

一、主要研究方向演变
├─ 早期（2010-2015）：聚焦电力电子变换器设计

三、署名习惯

四、学术影响力
├─ 高被引论文（前3）：XXX（引用452次）...

```

### 可以分析哪些问题？

使用AI，你可以快速了解：

✅ **研究方向是否匹配**
   - 导师的核心研究领域是什么？
   - 是否与你的兴趣方向一致？
   - 研究方向是否在拓展还是收缩？

✅ **科研活跃度**
   - 导师目前是否还在科研一线？
   - 最近几年发表频率如何？
   - 是否有转向行政岗的迹象？

✅ **培养模式**
   - 导师习惯让学生做一作吗？
   - 署名位置通常是什么？
   - 是否经常与学生合作发表？

✅ **学术影响力**
   - 哪些是导师的代表性工作？
   - 有没有高被引的经典论文？
   - 学术圈内的合作网络如何？

### 使用技巧

💡 **技巧1：分批分析**
如果论文太多（超过100篇），可以：
- 先分析最近5年的论文
- 再单独分析早期代表作
- 最后综合判断

💡 **技巧2：对比分析**
可以同时分析多位导师：
- 用本工具获取多位导师的数据
- 让AI对比他们的研究方向
- 帮助你选择最合适的导师

💡 **技巧3：追问细节**
得到初步报告后，可以继续追问：
- "请详细分析2020年后的研究转向"
- "哪些合作者是长期合作关系？"
- "是否有跨学科研究的趋势？"

⚠️ **隐私保护**
- 分析结果仅用于个人决策参考
- 不要公开传播或用于不当目的
- 尊重导师隐私和学术声誉
